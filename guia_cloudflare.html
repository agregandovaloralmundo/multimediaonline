📘 Guía Paso a Paso: Configurar tu Propia IA Rápida Gratuita (Cloudflare Workers AI)

Desplázate hacia abajo dentro de este panel para seguir los 6 pasos detallados o descárgalo en PDF

← Volver al Generador
ℹ️ Información importante sobre el servicio externo de Inteligencia Artificial:
Nuestra plataforma ofrece de forma gratuita una cuota diaria compartida lista para usar sin configurar nada. Si esa cuota se agota o deseas tener tu propia capacidad privada (~170 imágenes diarias en 2 segundos), puedes enlazar tu cuenta gratuita de Cloudflare Workers AI. Ten presente que Cloudflare es un proveedor externo independiente; si su panel cambia o necesitas soporte técnico sobre tu cuenta con ellos, consulta directamente su documentación oficial en developers.cloudflare.com/workers-ai o su panel en dash.cloudflare.com.
PASO 1 • Iniciar sesión o crear cuenta gratuita en Cloudflare
  • Abre una pestaña nueva en tu navegador y entra a dash.cloudflare.com.
  • En la pantalla Sign in to Cloudflare, haz clic en el botón Google para entrar directamente con tu cuenta de Gmail (o usa Sign up si prefieres otro correo). No solicita tarjeta de crédito.
PASO 2 • Entrar a Workers & Pages y crear una aplicación
  • En el menú lateral izquierdo, busca la categoría Build → Compute y haz clic en Workers & Pages.
  • Arriba a la derecha, presiona el botón azul Create application.
  • En la pantalla Make something new, haz clic en la opción Start with Hello World!.
PASO 3 • Asignar nombre y desplegar el Worker base
  • En el campo Worker name, borra el nombre aleatorio que aparece y escribe generador-ia (se formará una dirección como generador-ia.tu-usuario.workers.dev).
  • Deja apagado el interruptor Protect with Cloudflare Access y presiona el botón azul Deploy abajo a la derecha.
PASO 4 • Pegar el código puente de generación de imágenes
  • En el panel del Worker recién creado, haz clic arriba a la derecha en el botón </> Edit code.
  • En el editor izquierdo (worker.js), selecciona todo el texto de ejemplo (Ctrl + A), bórralo y pega exactamente el siguiente código:
export default {
  async fetch(request, env) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type",
    };
    if (request.method === "OPTIONS") return new Response(null, { headers: cors });
    if (request.method !== "POST") return new Response("OK", { headers: cors });
    try {
      const { prompt } = await request.json();
      const res = await env.AI.run("@cf/black-forest-labs/flux-1-schnell", { prompt, steps: 4 });
      const bin = atob(res.image);
      const bytes = new Uint8Array(bin.length);
      for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
      return new Response(bytes, { headers: { ...cors, "Content-Type": "image/jpeg" } });
    } catch (e) {
      return new Response(JSON.stringify({ error: e.message }), { status: 500, headers: cors });
    }
  }
};
  • Haz clic en el botón azul Deploy arriba a la derecha hasta que cambie a gris y muestre (Active) Latest.
  • Luego haz clic en < generador-ia arriba a la izquierda para volver a la vista principal del Worker.
PASO 5 • Conectar el permiso de Workers AI (Binding)
  • En la barra superior del Worker, entra a la pestaña Settings.
  • Baja hasta la sección Bindings y presiona el botón + Add binding.
  • En el menú de la izquierda selecciona Workers AI y haz clic en el botón azul Add Binding.
  • En el recuadro Variable name escribe exactamente AI (en mayúsculas) y vuelve a presionar Add Binding. Verás aparecer la fila Workers AI | AI | Workers AI Catalog confirmando el enlace.
PASO 6 • Guardar tu URL en Multimedia Online
  • Copia la dirección completa de tu Worker (ejemplo: https://generador-ia.tu-usuario.workers.dev).
  • Regresa a la pestaña de Generador de Imágenes con IA, haz clic en ⚡ IA Rápida Activa (o ⚙️ Mi Cuenta IA), pega tu URL en el campo URL Worker y presiona 💾 Guardar y Activar.
  • Nota de privacidad: Tu URL personal se almacena exclusivamente en tu navegador local y no altera la configuración del sitio para otros usuarios.
