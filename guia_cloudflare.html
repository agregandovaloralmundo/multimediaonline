📘 Guía Completa: Activar tu Propia IA Rápida Gratuita

Manual paso a paso para conectar tu cuenta gratuita de Cloudflare Workers AI (~170 imágenes/día sin espera)

← Volver al Generador
ℹ️ Aviso importante sobre el servicio de Inteligencia Artificial:
Nuestra plataforma ofrece de forma gratuita una cuota compartida para todos los visitantes. Si dicha cuota diaria se agota o deseas tu propia capacidad privada (~170 imágenes por día sin esperar), puedes enlazar tu propia cuenta gratuita de Cloudflare Workers AI. Cloudflare es un proveedor externo independiente; si ocurre algún cambio en su panel o tienes dudas sobre tu cuenta con ellos, consulta directamente su documentación oficial en developers.cloudflare.com/workers-ai o su panel en dash.cloudflare.com.
PASO 1 • Crear tu cuenta gratuita en Cloudflare

Abre dash.cloudflare.com en una pestaña nueva.

  • Haz clic en el botón Google para entrar directamente con tu correo de Gmail (o usa Sign up). No pide tarjeta de crédito.
PASO 2 • Entrar a Workers & Pages y crear la aplicación
  • En el menú lateral izquierdo, busca la sección Build → Compute y haz clic en Workers & Pages.
  • Arriba a la derecha, presiona el botón azul Create application.
  • En la pantalla "Make something new", selecciona la opción Start with Hello World!.
PASO 3 • Nombrar y desplegar el Worker inicial
  • En el campo Worker name, borra el nombre aleatorio y escribe generador-ia (verás que queda como generador-ia.tu-usuario.workers.dev).
  • Deja apagada la opción Protect with Cloudflare Access y haz clic en el botón azul Deploy abajo a la derecha.
PASO 4 • Pegar el código del puente de Inteligencia Artificial
  • En la vista general de tu Worker, haz clic arriba a la derecha en el botón </> Edit code.
  • En el editor izquierdo (worker.js), selecciona todo el código de ejemplo (Ctrl + A), bórralo y pega exactamente este código:
export default {
  async fetch(request, env) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type",
    };
    if (request.method === "OPTIONS") return new Response(null, { headers: cors });
    if (request.method !== "POST") return new Response("OK", { headers: cors });
    try {
      const { prompt } = await request.json();
      const res = await env.AI.run("@cf/black-forest-labs/flux-1-schnell", { prompt, steps: 4 });
      const bin = atob(res.image);
      const bytes = new Uint8Array(bin.length);
      for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
      return new Response(bytes, { headers: { ...cors, "Content-Type": "image/jpeg" } });
    } catch (e) {
      return new Response(JSON.stringify({ error: e.message }), { status: 500, headers: cors });
    }
  }
};
  • Haz clic en el botón azul Deploy arriba a la derecha hasta que cambie a gris y muestre (Active) Latest.
  • Haz clic en < generador-ia arriba a la izquierda para volver al panel del Worker.
PASO 5 • Conectar el permiso de Workers AI (Binding)
  • Entra en la pestaña superior Settings.
  • Baja hasta la sección Bindings y haz clic en el botón + Add binding.
  • En la lista de la izquierda elige Workers AI y presiona el botón azul Add Binding.
  • En el cuadro Variable name escribe exactamente AI (en mayúsculas) y presiona nuevamente Add Binding. Verás aparecer Workers AI | AI | Workers AI Catalog en tu tabla.
PASO 6 • Enlazar tu URL en Multimedia Online
  • Copia la dirección completa de tu Worker (ejemplo: https://generador-ia.tu-usuario.workers.dev).
  • Regresa al Generador de Imágenes, haz clic en ⚙️ Configurar Mi Cuenta IA, pega tu URL en el cuadro URL Worker y presiona 💾 Guardar y Activar.
  • Nota: Esta configuración se guarda únicamente en tu navegador personal y no modifica ni afecta el servicio de los demás usuarios.
